# Security Policy

RoboReplacer sits between you and your clipboard, so security and privacy reports are taken seriously.

## Supported versions

The project is pre-1.0. Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**.

This is a hobby project, so responses are best effort, but reports will be acknowledged and handled as quickly as time allows.

## What is in scope

- Any path by which clipboard content could be logged, stored, or sent off the machine
- Unexpected network access
- Malicious or malformed rule files (for example regular expressions designed to hang the application)
- Tampering with installers or release artifacts
